# MAX Messenger Notifications 0.7.0

## Обновление сообщений

Добавлены действия:

- `slava_max.edit_message` — редактирование ранее отправленного сообщения по `message_id`;
- `slava_max.send_or_update` — первое сообщение создаётся, последующие вызовы с тем же `key` обновляют его вместо создания новых сообщений.

Соответствие `key -> message_id` хранится в Home Assistant и сохраняется после перезапуска.

## Резервные уведомления

В настройках интеграции появился раздел **Резервные уведомления**.

MAX остаётся основным каналом. При ошибке отправки через MAX можно независимо включить:

- Home Assistant Push (`notify.mobile_app_*`);
- VK (`notify`-сущность, например `notify.poliarnaia`).

Отдельно настраивается резерв для обычных и аварийных сообщений.

Если MAX успешно принял сообщение, резервные каналы не вызываются.
